# Random Menu

Random Menu is a simple web application that recommends random menu options.

It is built with HTML, CSS, and JavaScript, and stores user-entered menu data in `localStorage`.
The app can also be added to the home screen on iPhone and Android devices, and it works offline.

## Features

- Add and manage custom menu items
- Recommend a random menu
- Save menu data using localStorage
- Mobile-friendly layout
- Can be used as a simple PWA-style web app
- Works offline after being added to the home screen

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

## Project Purpose

This project was created as a lightweight personal web app for recommending random menus.
It focuses on simple UI, local data storage, mobile usability, and offline-friendly behavior.
